# UNO Server 功能需求

> 范围：练手级多人 UNO 对战服务。  
> 本文只描述「做什么」和「按什么规则玩」，不涉及技术实现。  
> 服务端为规则唯一权威；客户端不可信。

**状态：** 已确认（开放问题已拍板）  
**最后更新：** 2026-08-03

---

## 1. 产品目标

玩家可创建或加入房间，在房间内完成一局（或多局）标准 UNO 对战；服务端判定规则、推进回合、公布结果。

**本期目标体验：**

1. 能稳定打完一局完整 UNO  
2. 断线后能回到同一房间并继续（断线期间走托管）  
3. 操作非法时有明确提示，不以客户端为准  

---

## 2. 角色

| 角色 | 说明 |
|------|------|
| 游客/玩家 | 获得身份后进入房间，参与对局 |
| 房主 | 房间创建者；可踢人、开始游戏（在规则允许时） |
| 系统 | 发牌、校验、结算、超时处理、房间回收 |

## 3. 功能清单

### 3.1 账号与身份（极简）

| 编号 | 需求 | 说明 |
|------|------|------|
| F-ACC-01 | 进入服务 | 玩家获得唯一 `playerId` 与展示昵称 |
| F-ACC-02 | 昵称 | 可设置昵称；重名允许（用 id 区分） |
| F-ACC-03 | 无强账号体系 | 本期不做注册/密码/邮箱；可用游客或一次性 token |

### 3.2 大厅 / 房间

| 编号 | 需求 | 说明 |
|------|------|------|
| F-ROOM-01 | 创建房间 | 房主创建；配置：人数上限（2–6） |
| F-ROOM-02 | 加入房间 | 通过**房间号**加入（本期不做房间列表、不做密码房） |
| F-ROOM-03 | 离开房间 | 主动离开；房主离开则转移房主或解散（见 4.9） |
| F-ROOM-04 | 踢人 | 仅房主、仅「未开局」可踢 |
| F-ROOM-05 | 准备 | 非房主需准备；可取消准备；房主默认视为已准备 |
| F-ROOM-06 | 开始游戏 | 人数 ≥ 2 且全员已准备时，房主可开局 |
| F-ROOM-07 | 房间状态展示 | 对房间内所有人同步：成员列表、准备状态、是否在对局中 |
| F-ROOM-08 | 再来一局 | 结算后可回到等待态，保留成员，重新准备开局 |
| F-ROOM-09 | 空房回收 | 房间无人持续一段时间后销毁 |

### 3.3 对局中操作

| 编号 | 需求 | 说明 |
|------|------|------|
| F-GAME-01 | 发牌与开局 | 按规则洗牌、发牌、亮出第一张弃牌 |
| F-GAME-02 | 出牌 | 当前回合玩家选择合法手牌打出 |
| F-GAME-03 | 摸牌 | 当前回合无法/选择不打时摸牌（细则见 4.4） |
| F-GAME-04 | 选色 | 打出万能牌后选择颜色 |
| F-GAME-05 | 喊 UNO | 手牌将变为 1 张时需喊 UNO（细则见 4.7） |
| F-GAME-06 | 质疑 UNO | 其他玩家可在时限内质疑未喊 UNO 者 |
| F-GAME-07 | 特殊牌效果 | Skip / Reverse / +2 / Wild / Wild+4 按规则生效；**+2/+4 允许叠加** |
| F-GAME-08 | 回合提示 | 同步：当前出牌人、方向、顶牌、当前颜色、各玩家手牌数量、当前累计惩罚（若有） |
| F-GAME-09 | 私有手牌 | 仅自己可见完整手牌 |
| F-GAME-10 | 胜负与结算 | 有人手牌为 0 则结束本局并计分/公布结果 |
| F-GAME-11 | 操作校验失败 | 非法出牌/非自己回合等返回原因，不改变牌局 |

### 3.4 超时与托管

| 编号 | 需求 | 说明 |
|------|------|------|
| F-TIME-01 | 出牌限时 | 每回合有倒计时（建议默认 20s，可配置） |
| F-TIME-02 | 超时自动操作 | 超时：若有可出牌则随机出一张合法牌；否则摸 1 张并按 4.4 处理 |
| F-TIME-03 | 选色超时 | 万能牌选色超时则随机颜色 |
| F-TIME-04 | 连续超时 | 连续 N 次超时（建议 2）进入托管；托管按「能出则出，否则摸」自动打 |

### 3.5 断线与重连

| 编号 | 需求 | 说明 |
|------|------|------|
| F-NET-01 | 断线保留座位 | 对局中断线不立刻踢出，座位保留一段时间 |
| F-NET-02 | 重连恢复 | 重连后恢复：房间状态 + 公开桌面 + 自己手牌 |
| F-NET-03 | 断线期间 | 到其回合且仍断线：走超时/托管逻辑 |
| F-NET-04 | 对局中主动退出 / 超时未重连 | **托管打完本局**，不立刻判他人胜利；局结束后可移除座位 |

### 3.6 本期不做（明确非目标）

- 房间列表、密码房  
- 累计分赛（先到 N 分整场胜利）  
- Wild+4「无同色才可出」的服务端限制与被 +4 后的挑战流程  
- 排行榜、好友、商城、观战、录像回放  
- 完整官方所有变体规则包  
- 跨服匹配、俱乐部、语音  
- 复杂账号安全体系  
- 房间文字聊天（可二期）

## 4. 游戏规则（本期采用的 UNO 子集）

> 下列为**服务端唯一权威规则**。与市面实体牌/App 若有出入，以本文为准。

### 4.1 人数与牌库

| 项 | 规则 |
|----|------|
| 人数 | 2–6 人 |
| 初始手牌 | 每人 **7** 张 |
| 牌库组成 | 标准 108 张（见下表） |
| 公开信息 | 弃牌堆顶牌、当前生效颜色、方向、轮到谁、每人剩余张数、当前累计惩罚张数（叠罚进行中时） |
| 私有信息 | 仅自己的手牌；摸牌结果仅本人立刻知晓，他人只看到张数变化 |

**标准 108 张构成：**

| 类型 | 数量说明 |
|------|----------|
| 数字 0 | 四色各 1 张，共 4 |
| 数字 1–9 | 四色各 2 张，共 72 |
| Skip（跳过） | 四色各 2，共 8 |
| Reverse（反转） | 四色各 2，共 8 |
| Draw Two（+2） | 四色各 2，共 8 |
| Wild（变色） | 4 |
| Wild Draw Four（变色+4） | 4 |

颜色：红 / 黄 / 绿 / 蓝。

### 4.2 开局

1. 洗牌，每人发 7 张。  
2. 从牌库翻开第一张作为弃牌堆顶。  
3. **若第一张是：**
   - **数字牌**：正常，以该牌颜色与点数为当前约束；由座位顺序中起始玩家的下一位先出（座位顺序开局前固定）。  
   - **Skip**：起始玩家被跳过，下一位出牌。  
   - **Reverse**：**2 人局**等同 Skip；**3–6 人局**改变方向后，由新方向上的下一位出牌。  
   - **+2**：起始玩家摸 2 张并被跳过。  
   - **Wild**：起始玩家选色后自己出第一张。  
   - **Wild+4**：**不允许**作为开局亮牌；重新塞回牌库洗牌再翻，直到合法。  

### 4.3 回合与出牌合法性

- 任意时刻仅有一名「当前玩家」。  
- 出牌须满足 **之一**：
  1. 与顶牌 **同色**；或  
  2. 与顶牌 **同点数 / 同功能类型**（如都是 Skip、都是 5、都是 +2）；或  
  3. **Wild / Wild+4**（Wild+4 **不**额外限制「手中有无同色牌」）。  
- 打出有色功能牌后，当前颜色变为该牌颜色。  
- 打出 Wild / Wild+4 后，玩家必须声明一种颜色，之后只认该颜色（点数约束解除，直到下张有色牌）。  
- **每次正常回合默认只出 1 张**（不做「同点连出」）。  
- **叠罚进行中**时，当前玩家的可选行动见 4.5，不按普通「同色/同点」自由出任意牌。

### 4.4 摸牌规则

当玩家在**非叠罚**的普通回合选择摸牌，或超时且无合法出牌时：

1. 从牌库摸 **1** 张。  
2. 若该牌 **当前可出**，玩家可选择立即打出，或留在手中结束回合。  
   - **超时 / 托管**：可出则自动打出；不可出则结束回合。  
3. 若不可出，该牌加入手牌，结束回合。  
4. **不做**「一直摸到能出为止」。

> 叠罚进行中的「摸牌」见 4.5：摸的是累计惩罚张数，不是上述「摸 1 张再考虑出」。

### 4.5 特殊牌效果

| 牌 | 效果 |
|----|------|
| **Skip** | 下一位玩家跳过其回合 |
| **Reverse** | 出牌方向取反；**2 人局**视为 Skip（对手被跳过） |
| **+2** | 对下家施加（或累加）惩罚，见下方叠罚规则 |
| **Wild** | 出牌者指定颜色 |
| **Wild+4** | 出牌者指定颜色，并对下家施加（或累加）惩罚，见下方叠罚规则 |

#### 4.5.1 叠罚规则（+2 / +4 允许叠加）

1. **惩罚池（draw stack）**  
   - 当有人打出 +2 时，惩罚池 `pendingDraw += 2`。  
   - 当有人打出 Wild+4 时，惩罚池 `pendingDraw += 4`，并完成选色。  
   - 轮到下家时，若 `pendingDraw > 0`，该玩家处于「被罚响应」状态。

2. **被罚响应时，当前玩家仅可：**  
   - **叠加**：打出 **+2 或 Wild+4**（二者可互相叠加），将对应张数并入惩罚池，选色（若是 Wild+4）后，惩罚转移给新的下家；或  
   - **承受**：不叠加，从牌库摸 `pendingDraw` 张，清空惩罚池，并**跳过本回合**（摸完不能再出牌）。

3. **不能**在被罚响应时用普通牌、Skip、Reverse、Wild（非 +4）来「挡」惩罚。  
4. 惩罚池为 0 时，恢复普通出牌/摸牌规则。  
5. **超时 / 托管**处于被罚响应：默认 **承受**（摸满惩罚张数并跳过）。

#### 4.5.2 Wild+4 出牌限制

- **不做**「手中没有当前颜色有色牌才可出 Wild+4」的校验。  
- **不做**被 +4 后「质疑对方是否违规」的挑战流程。  
- 只要当前规则允许出万能牌（普通回合按 4.3；被罚响应时允许用 Wild+4 叠加），即可打出。

### 4.6 牌库耗尽

- 牌库抽空时：将弃牌堆 **除顶牌外** 全部洗回作为新牌库，顶牌保留。  
- 若仍不够抽（极端）：按「可抽多少抽多少」；正常对局几乎不触发。

### 4.7 UNO 喊牌与质疑

1. 玩家打出后手牌剩余 **1** 张时，必须在出牌同时宣告 UNO（协议上由出牌请求携带 `sayUno=true`，或等价短时限内补喊，建议与出牌同一请求完成）。  
2. 若未宣告，进入「可被质疑」状态。  
3. 其他玩家可在约定窗口内发起「抓 UNO」（建议：该玩家再次行动前，或固定 **3–5 秒** 窗口，实现时二选一写死）。  
4. 抓成功：被抓者摸 **2** 张，清除「可被质疑」状态。  
5. 手牌从 1 张又变回多张后，UNO / 可被质疑状态清除。  
6. 打出最后一张（手牌为 0）时无需喊 UNO，直接进入胜负结算流程。

### 4.8 胜利与计分

**胜负：**

- 任一玩家出完最后一张且该牌效果结算完毕后，若其手牌为 0，则该玩家本局胜利。  
- 若最后一张是 +2 / +4 / Skip 等，先结算对下家的效果（含叠罚转移），再判定胜负。  
- 本期只做**单局**胜负；不做「累计分先到 N 分赢得整场」。

**计分（单局）：**

- 胜者得分为 **其余玩家手牌点数之和**。  
- 点数：0–9 为面值；Skip / Reverse / +2 = 20；Wild / Wild+4 = 50。  
- 单局结束展示：胜者、各人手牌剩余、本局得分。

### 4.9 房间级规则

| 编号 | 规则 |
|------|------|
| R-ROOM-01 | 开局后不能加入新玩家 |
| R-ROOM-02 | 对局中离开或长时间断线：该位置 **托管打完本局**，不立刻判其他人胜利 |
| R-ROOM-03 | 只剩 1 名「非托管真人」且其余均为托管时：仍可继续自动打完；或实现上允许提前结束并按当前手牌计分（实现阶段二选一，优先「托管打完」以简单一致） |
| R-ROOM-04 | 未开局：房主可解散房间；开局中不可解散 |
| R-ROOM-05 | 房主在等待阶段离开：将房主转移给下一位仍在房间的玩家；若无人则销毁房间 |

## 5. 典型用户流程（验收用）

1. A 创建房间 → 得到房间号 → B、C 输入房间号加入 → 全员准备 → A 开局  
2. 系统发牌，轮到 A → A 出合法牌 → 效果生效 → B 的回合  
3. B 无牌可出 → 摸 1 张 → 能出则打出或保留 → 下一玩家  
4. A 出 +2 → B 再出 +2 叠加 → C 选择承受摸 4 张并跳过  
5. D 剩 1 张时喊 UNO → 出完最后一张 → 结算单局得分  
6. 中途 B 断线 → 超时托管 → B 重连恢复手牌与桌面 → 继续；或 B 主动退出 → 托管至局终

## 6. 已拍板结论（原开放问题）

| # | 问题 | 结论 |
|---|------|------|
| Q1 | +2 / +4 是否允许叠加？ | **允许**（见 4.5.1） |
| Q2 | 摸牌后是否允许立刻打出？ | **允许**（见 4.4） |
| Q3 | Wild+4 是否校验「无同色才可出」？ | **不做**（见 4.5.2） |
| Q4 | 是否做 UNO 质疑？ | **做**（见 4.7） |
| Q5 | 对局中主动退出 | **托管打完本局**（见 F-NET-04、R-ROOM-02） |
| Q6 | 密码房、房间列表 | **不做**；仅房间号加入 |
| Q7 | 计分累计到 N 分整场胜利 | **不做**；仅单局胜负 + 单局分 |
| Q8 | 2 人局 Reverse | **等同 Skip** |
